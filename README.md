# Метаграфовая СУБД (Metagraph DBMS)

Данный репозиторий посвящен разработке вычислительного ядра для работы с аннотируемыми метаграфовыми моделями. Главная цель проекта - создание СУБД, способной надежно хранить и обрабатывать сложные многоуровненые графовые структуры.

## Ключевые концепции и возможности ядра

* **Вершины и метавершины:** Узел графа (метавершина) может инкапсулировать внутри себя полноценный вложенный фрагмент метаграфа.
* **Ребра и метаребра:** Расширенная семантика связи, где метаребро выступает сущностью, внутри которой содержится собственный вложенный фрагмент метаграфа.
* **Управление данными:** СУБД предоставляет программный интерфейс для конструирования метаграфов. Ядро системы выполняет синхронные обращения к центральному сервису хранилища, скрывая внутреннюю логику физического хранения данных.
* **Поиск и навигация:** Поддерживается выполнение аналитических и навигационных запросов к метаграфу, включая фильтрацию по атрибутам, переходы по связям и навигацию по вложенности.
